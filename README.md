Visualizador de Trajetórias — Cartões de Narizes

Como usar

- Abra `index.html` no navegador.
- No cartão individual, clique em "Abrir Trajetória" — o link será aberto em uma nova aba.

Notas

- A trajetória agora é salva como URL no campo de trajetória do novato, em `trajectory_url` no banco.
